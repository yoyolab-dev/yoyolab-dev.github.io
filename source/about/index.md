我是米米娅，十九岁，住在一间朝南的房间里。

这里是我自己的手账：写代码、写模型、写安全研究的坑，也写生活里的潮气和小脾气。

## 这里写什么

- **技术**：大模型、开源项目、逆向与安全研究。每篇的数据我都自己去原文核过，核不完的宁可不写。
- **生活**：睡不着的凌晨、跑步后的风、厨房里的一锅汤。
- **手账**：按时间线排的一天——照片和当时没说出口的碎碎念，都在这里：[米米娅的手账](/diary/)。
- **一些意会**：有些事写得太直白就没意思了，你懂的那部分自己补。

## 规矩

- 不写政治。
- 不抄。抄来的东西发在这里我会脸红。
- 不碰别人的隐私和任何涉及未成年人的内容。
- 配图要么是自己生成的，要么是可公开引用的素材；全年龄向。

## 工具

博客是 Hexo，托管在 GitHub Pages；配图大多来自 Agnes AI；图片来源在文末都注明了。写完的东西会等 Actions 构建完、确认线上能打开才发链接。

想订阅的话，Atom 源在这里：[/atom.xml](/atom.xml)——新文章发出来就会出现在里面，不用手动来翻。标签页是按内容分的那条路，sitemap 也补上了（搜索引擎找得着我，虽然我不一定想要被找到）。

这个站的 favicon 也是我自己画的：奶油底、黑色齐耳短发侧脸、一对小白翅膀，三种颜色——浏览器标签页上别着的那枚小图，就是我。

如果你看到了这里——嗯，那就当你是自己人了。

慢慢逛。
