HelloGitHub 上刷到的这个项目，名字挺讲究：[DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map)，**江山时序 · Chronicles of the Realm**。

JavaScript 写的，GPL-3.0，四千七百多星、五百多个 fork，**open issue 只有 8 个**——这个数字对一个这么大体量的可视化项目来说，说明它被用得很稳。仓库是今年 7 月 23 号建的，昨天还在提交。

它做的事一句话说完：**把公元前 403 年到今天的 2400 多年中国史，做成一张可以拖着走的羊皮纸地图。**

## 它到底装了多少东西

- **18 个历史时期**，**164 张疆域快照**，而且是"多阶段"的——同一个朝代内部还有好几次领土变动，每一张都是独立快照
- 古城、关隘、诗里写过的地名、战场遗址、时间轴上的里程碑，以及**当时的皇帝和年号**
- 多语言界面（英文 / 简体中文 / 日本語），在线 demo 直接能玩

有意思的是它的视角：不是"按朝代切地图"，而是**按历史里程碑切**。README 里随手列的那些节点，随便挑一个都够讲一段：

> 秦灭巴蜀（公元前 316 年）· 燕将秦开拓辽东（公元前 300 年）· 马援在交趾立铜柱（43 年）· 司马懿伐辽东（238 年）· 李靖灭吐谷浑（635 年）· 安西四镇与王玄策在中亚的仗（648 年）· 元朝宣政院辖地（1288 年）· 明代哈密与嘉峪关七卫（1404 年）· 1881 年圣彼得堡条约收回伊犁 · 1898 年租借地 · 1946 年从"秋海棠图"换成"雄鸡图"。

## 我最喜欢的一个设计

切换任何一个里程碑，地图上会画出**上一阶段的边界，用朱红色虚线**——作者管它叫 "Ghost Boundary Diff"，幽灵边界差分。

意思是：你拖到 648 年，看到唐朝的疆域，同时那条朱红虚线还留着 635 年之前的样子，一眼就知道这一阶段**吞了哪块、吐了哪块**。

静态地图只能告诉你"当时有多大"，这种做法能告诉你**变化的方向**。这是我今年见过的最聪明的一个交互。

另外还有两个细节：**X-Ray Lens** 可以把今天的省界直接投到历史地图上做对照；点任何一座古城，能顺着"地名谱系"看它两千四百年的名字变迁——长安在不同年代叫什么、建康今天在哪儿、黄州是苏轼写赤壁赋的地方吗，都能一路点下去。

河流也不甘落后：黄河改道、云梦泽的涨落、罗布泊的消失、战国到明的长城、隋唐大运河、丝绸之路、郑和的航线，全都跟着时间轴同步变形。

## 它给"李白苏轼"开了单独一条线

这个项目最勾我的其实是它的另一半：**古典诗歌行程路线**。

README 里问的那个问题就是它的动机：建康在今天地图的哪个位置？黄州、赤壁、秦岭里的蓝关、岳飞北伐的前线朱仙镇，究竟在哪儿？点开苏轼被贬那条路线，看他一路从汴京走到黄州再到惠州儋州，地图上会有一条线慢慢画出来。

我试了 demo：拖时间轴的手感很顺，切换一个年份，疆界颜色、君主名字、年号、河流一起变。像做历史题时那种"突然把平面图换成沙盘"的感觉。

## 顺带说一句作者

README 里挂了作者自己写的一篇文章，标题就叫《From textbook maps to 1k GitHub stars》——从教科书地图到一千星。一个 2026 年 7 月才建的项目，能做到 GitHub Trending 当日第二，仓库里还挂着这个徽章，说明它不是靠话题营销，是真有人日日在用。

---

这种项目最怕的不是技术难，是**数据维护**：164 张疆域快照、每张还要对得上府一级行政区，任何一处史料对不上就会被揪出来。8 个 open issue 里多半还有几条是纠错的。这种活儿愿意做的人不多，愿意公开让别人一起纠的更少。

想翻历史的人，拖一遍就知道值不值。
