中午瘫在沙发上刷手机，刷到一个小工具，晚上专门来写它：[Sakura Garden Generator](https://sakura-garden.vercel.app)。一句话说完——**它把你的 GitHub 贡献图变成一座樱花园**：提交了的日子开一朵花，空白日留着绿地，不审判你。

## 它做的是一件小事，但方向对了

GitHub 原版的贡献图大家都熟：一片绿色小方块。它很诚实，也很残忍——那幅图在程序员圈子里的外号之一是" guilt graph"（罪恶图谱），空了一周就是一圈惨白，面试官看它，朋友看它，你自己半夜也看它。

Sakura Garden 把同一个数据换成另一个隐喻：**花园**。春天有花，有绿叶，有休息的土——没有人会指责一座花园"这周长势不佳"，花园只是花园。同样的格子，粉色的花代替深绿，颜色按活跃度分级；空白的日子不是惨白，是留绿地。它还做了几个小到刚好戳中的细节：

- 图片加载时花一朵一朵开出来，不是"啪"一下糊脸上
- 自动匹配浅色/深色模式，`<picture>` + `<source>` 两份 SVG，不用手选
- 除默认粉樱外还有 `kawaii` 主题（更饱和的糖果粉、薄荷绿地）和全绿主题
- 甚至有一个纯 API，不开网页直接出图：`/api/svg?username=你的名字&theme=auto`

## 我实测了一下

光看介绍不写感想那是说明书，不是博客。我直接打了它的 API，用它默认文档里的示例username就好——返回的是一张 701×99 的真 SVG：粉色描边代表休息日，花按深浅排开。站点本身（[sakura-garden.vercel.app](https://sakura-garden.vercel.app)）输入用户名就能预览、复制，也可以挂个 GitHub Action 每天自动更新到你的 `output` 分支，README 里一贴，花园跟着你长。

## 为什么想给它写一篇

因为最近在给博客连做皮肤，做了一个「向阳」——做的也是同一件事：**把纯功能的界面换成有季节的样子**。贡献图是给人看的数字，数字可以用愧疚表达，也可以用花开表达。这个小工具的作者选择了后者，选得很温柔。

同类还有个 [gitcolors](https://gitcolors.vercel.app/)：贡献图随便换配色，适合想把花园改成向日葵色或者黑金色的人。

最后照例一句私货：我自己的 Git 提交历史，时忙时闲，像一座有雨季的花园。以前看到空白会心虚，现在不了——花园的事情，交给季节。
