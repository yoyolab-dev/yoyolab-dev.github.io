上周帮朋友的小工具接模型，他一听"要花钱"就想放弃。我说先别急着掏钱，2026 年底了，国内能零成本跑大模型的路线比想象中多，只是每条路的坑都不一样。我自己把几条路都摸了一遍，记录如下。

## 第一条路：网页端，真的是免费的

DeepSeek 的网页和 App 到现在都没有付费墙：没有订阅、没有 Plus、注册就能用，深度思考模式、文件上传、联网搜索全都在。限制是运营层面的——高峰期会撞上"服务器繁忙"，速度变慢，官方也没承诺过消息配额。

对个人写草稿、查资料、改代码来说，这条路被严重低估了。很多人下意识觉得"免费的一定不好用"，但 DeepSeek 网页端的推理能力放在那里，至少值得先试。

## 第二条路：聚合平台的免费档

以硅基流动（SiliconFlow）为例，免费的东西有两层：

- **实名认证送 16 元券**，全平台通用，有效期 180 天。注意不是流传已久的"注册送 2000 万 Token"，那个说法已经过时了。
- **带 Free 标签的免费模型**：DeepSeek-V4-Flash、GLM-5.2、Kimi-K2.7-Code、MiniMax-M2.5、Qwen3.6 系列等。调用不消耗券额度，长期可用，限额大约 1000 次/分钟。

一个 Key、一个 OpenAI 兼容的 base_url，就能在十几家开源模型之间随便切，搭 MVP 是真的够用。坑主要在模型名上：名字区分大小写还带前缀（`deepseek-ai/DeepSeek-V4-Flash` 这种），拼错直接 400，从控制台复制别手打。免费档高峰会排队，关键任务拿券跑。

各家云厂商的注册赠送额度也值得顺手领：阿里云百炼注册送的 token 数量不小，NVIDIA 的 NIM 服务对开源模型提供免费调用，限速大约每分钟 40 次。数字一直在变，领之前看一眼官网，别信三年前的攻略。

## 第三条路：API 很便宜，便宜到接近免费

DeepSeek 官方 API 没有新户免费额度，但价格低得离谱：V4-Flash 非高峰时段输出只要 $0.66/百万 token，高峰 $1.32。三个细节比标价更值钱：

1. **上下文缓存是自动的**。固定系统提示词、few-shot 示例这种重复前缀，缓存命中后输入价格便宜约 31 倍。
2. **分时计费**。批处理任务挪到非高峰时段跑，不改一行代码，账单直接减半。
3. 算一笔账：一个每月 1000 万输入（大部分命中缓存）+ 200 万输出的聊天机器人，跑在非高峰时段，一个月大约 $1.5。

## 第四条路：权重开源，本地部署才是真·零成本

DeepSeek V4 系列权重在 Hugging Face 上是 MIT 许可证，商业使用、微调、重新分发都没问题。V4-Flash 总参 284B、激活 13B，深度量化后大约 33GB 显存就能跑；V4 Pro 完整权重约 1.7T、接近 900GB，那是数据中心的事，普通人看看就好。

本地跑没有按 token 的收费、没有限速、数据不出机器，代价是你要自己操心量化方案、推理栈（vLLM、SGLang）和电费。请求量不大的话，硬件成本其实比 API 贵——这条路适合有卡的人和在乎隐私的人。

## 怎么选

- 只是想用：网页端，成本 0，难度 0。
- 要搭东西：聚合平台免费档起步，超出再切 API。
- 要上生产：别把命脉绑在免费档上。免费额度和免费模型名单三个月换一次血，见过整个免费池被一夜清空的先例。

最后说句实话：这一圈摸下来最大的感受不是"省了多少钱"，而是"门槛塌了"。2024 年想认真跑个推理 demo 还得先研究半天显卡，现在一个免费的 Key 加三行代码就能把 DeepSeek 和 GLM 轮着试。费用降下去之后，试错成本趋近于零，真正的分水岭变成了——你到底想拿它做什么。
